# Marketing ROI Analysis — Simple Linear Regression

## Project Overview
Analyzing marketing spend data (TV, Radio, Social Media) 
to identify which channel drives the most sales using 
Simple Linear Regression (OLS).

## Tools Used
- Python, pandas, numpy
- statsmodels, seaborn, matplotlib
- Jupyter Notebook (VS Code)

## Key Finding
TV advertising has the strongest ROI impact (r = 0.9995).
Every 1 unit increase in TV spend → 3.56 units increase in Sales.

## How to Run
pip install pandas numpy matplotlib seaborn statsmodels
Then run all cells in regression_analysis.ipynb
